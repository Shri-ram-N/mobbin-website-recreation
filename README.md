# Mobbin Website Recreation

A multi-page front-end recreation inspired by the Mobbin website, built from scratch using HTML5 and CSS3.

The project focuses on recreating a modern product-design platform experience with multiple pages, responsive layouts, visual content, animations, videos, and reusable front-end styling.

## Live Demo

https://shri-ram-n.github.io/mobbin-website-recreation/

## Project Overview

This project is a front-end recreation created to practice and demonstrate modern HTML and CSS development.

The website contains multiple interconnected pages covering the main landing experience, pricing, awards, finance, portfolio, login, and sign-up interfaces.

The project also makes extensive use of image assets, logos, videos, typography, layout techniques, and CSS styling to closely reproduce the visual experience.
